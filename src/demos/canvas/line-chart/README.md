# 手写折线图 Line Chart

> 分组：Canvas 2D ｜ 难度：★★★ ｜ 建议先做原生版

## 练习目标

- 数据域到画布坐标的映射（scale）
- 坐标轴、刻度、网格线的布局算法
- 折线 / 面积路径、渐变填充、裁剪
- hover 命中检测与 tooltip
- 动画、响应式、DPR 适配
- 理解图表库内部到底做了什么

## 业务对应

运营报表、监控面板、数据大屏、埋点趋势图。这是最能综合锻炼 Canvas 能力的练习。

## 原生版实现要点

1. **布局**：定义 `padding`，得到绘图区 `plotWidth/plotHeight`；标题、图例、轴标签都占用布局空间。
2. **比例尺**：X 轴按索引或时间线性映射，Y 轴从 `[min, max]` 映射到画布高度（注意 y 轴翻转）。
3. **刻度算法**：先实现等分刻度，再了解 `nice number` 算法，避免出现 `0.3333` 这类刻度。
4. **绘制顺序**：网格 → 轴线 → 面积 → 折线 → 数据点 → tooltip。
5. **命中检测**：鼠标移动时把屏幕 x 换算回数据索引，取最近点显示 tooltip；点少时可直接遍历。
6. **动画**：用进度值插值 y 坐标，或实现从左到右的裁剪展开。
7. **响应式**：监听容器尺寸，重新计算布局；DPR 缩放保证清晰。

## 库版对照（ECharts）

- 用 `setOption` 描述配置，内部完成布局、动画、交互、图例、缩放；
- 对比点：手写版需要自己处理的「刻度、布局、命中、动画」，ECharts 分别用什么机制解决？
- 也值得对比 Chart.js（更轻）和 D3（更底层、偏数据驱动 DOM/SVG）。

## 验收清单

- [ ] 任意数据（含负数、相同值、空数据）都能正确绘制且不越界
- [ ] 坐标轴刻度合理，标签不重叠
- [ ] hover 能高亮最近点并显示 tooltip
- [ ] 容器缩放后图表自适应，文字清晰
- [ ] 数据更新时有简单过渡动画

## 可以继续扩展

- 多系列、图例开关
- 柱状图 / 饼图复用同一套布局与比例尺
- 缩放与平移（brush、dataZoom）
- 大数据量下的降采样
- 导出 PNG

## 常见坑

- Y 轴方向未翻转，数据画反。
- 数据范围为零时除零，出现 `Infinity/NaN`。
- tooltip 用 DOM 绝对定位时坐标系没换算。
- resize 后只改 CSS 尺寸，没有重设位图尺寸。
